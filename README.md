# 📄 Local & Cloud-Ready RAG PDF Chatbot

A modular Retrieval-Augmented Generation (RAG) system built with **LangChain**, **ChromaDB**, and **Streamlit**, supporting multiple backend engines (**Google Gemini**, **Ollama**, and **OpenAI**).

---

## 🚀 Tech Stack
- **UI:** Streamlit
- **Orchestration:** LangChain / LangChain Expression Language (LCEL)
- **Vector Database:** ChromaDB (Local persistent storage)
- **Document Loading:** PyPDF / LangChain Document Loaders
